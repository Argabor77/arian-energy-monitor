# v0.3.2 — Complete Energy Dashboard (beta)

## English
- Dedicated weekly device comparison and six-month history, with grouped and stacked charts.
- Select any past day using the calendar or previous/next controls; see hourly consumption and device distribution.
- Switch all visualizations between kWh and estimated cost; toggle individual devices and inspect each period.
- Existing card configuration works without migration. No extra dashboard cards or YAML are needed.

## Update / Aktualisierung / Güncelleme

[Open in Home Assistant Marketplace](https://my.home-assistant.io/redirect/marketplace_repository/?owner=Argabor77&repository=arian-energy-monitor&category=plugin). Update and refresh the browser.

Historical data requires Recorder sum statistics. Missing data is not measured zero. Costs are estimated using the current tariff, excluding fixed charges. Beta release; nine automated tests pass. Weekly and six-month charts, selected-day distribution, hourly data, date navigation, cost switching and chart style were verified on a live Home Assistant test dashboard.
